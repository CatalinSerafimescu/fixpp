# ⚠️ WHERE THE RIGHT-HAND SIDE COMES FROM, because it is the load-bearing half and it
# is NOT this file's doing: expected-skips-without-counterparty.txt is held to the

# that on its own and never claimed to; it composes with that one.
#
# ⚠️ And the composition has an ORDER: the tiers run only once the gate labels land,
# while the interop-live job is advisory and runs from the first push. So a green
# interop-live PRECEDES the population guarantee rather than establishing it.

# counterparty is leased, and on its own it is satisfied equally by a case that runs
# everywhere and by one that runs NOWHERE. This file is the difference, stated out

# checker re-derives; an id filed under the wrong group fails even though the

#
