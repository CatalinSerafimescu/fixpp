# ci/expected-shipped-doc-files.txt
#
# The attribution + licence set that EVERY shipped artifact must carry, given as
# paths under the install DOCDIR (CMAKE_INSTALL_DOCDIR = share/doc/fixpp).
#
# WHY THIS IS A FILE AND NOT TWO LITERAL LISTS (#255)
# Two witnesses assert this set, in different languages, from different jobs:
#
#   tests/packaging/run_package_contents_witness.cmake  the tar.gz/deb/rpm/zip
#                                                       packages, via CTest
#   ci/check-wheel-payload.sh                           the manylinux wheel, via
#                                                       a tier1 step in another job
#
# They cannot be merged: the wheel is built by cibuildwheel in a container, in a
# job with no CTest tree. But a set spelled twice drifts, and it drifts in the
# direction that matters - add a fifth attribution file, update one witness, and
# the other artifact ships without it while both gates stay green. So the SET
# lives here once, and each witness adds only what is peculiar to it (the
# packages additionally require fixpp-package-provenance.txt, a CPack artifact
# correctly absent from the wheel).
#
# These are OBLIGATIONS, not conveniences. The first two are the terms fixpp is
# distributed under; the last two discharge QuickFIX licence clauses 1-3 and
# attach to the redistributed dictionary XML, which the wheel also carries in
# _fixpp_data/. Deleting a row here silently stops BOTH artifacts asserting it.
#
# ASCII ONLY, AND THAT IS ENFORCED, NOT MERELY REQUESTED.
# CMake's file(STRINGS) extracts ASCII strings and SPLITS a line at a non-ASCII
# byte, so an em dash or an emoji in a COMMENT breaks it into fragments; the
# first still starts with '#', the rest do not. Measured: an earlier draft of
# this file used typographic punctuation and the CMake witness parsed 10 members
# out of 4.
#
# Both readers now VALIDATE rather than filter - they take every non-comment row
# and hard-error on any that is not [A-Za-z0-9_.-]+ - so such a fragment is a
# loud failure instead of a phantom member, and a non-ASCII byte anywhere in
# this file will stop the build rather than corrupt the set. Keep it ASCII.
#
# !! The two grammars must stay identical. If a filename ever legitimately needs
# a character outside that class, change BOTH readers together:
#   tests/packaging/run_package_contents_witness.cmake  (the packages)
#   ci/check-wheel-payload.sh                           (the wheel)
# Both are exercised by ci/test-check-wheel-payload.sh, which pins the malformed
# and non-ASCII rows as RED cells.
#
# Format: one DOCDIR-relative filename per line; '#' comments and blanks ignored.
LICENSE
LICENSE-COMMERCIAL.md
NOTICE
