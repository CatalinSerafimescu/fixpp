# ⚠️ THIS BATCH USES ONE RECIPE SHAPE: `run_window_then_ready` + `drain_or_report` +
# `ADD_FAILURE` + `return;` at every site, which is why the file is short where batch
# 13's was long.
#
# ⚠️ THE FIRST DRAFT OF THIS PARAGRAPH JUSTIFIED THAT WITH A FALSE CLAIM -- *"every site
# is in a file whose fixture has NO Clock, so there is none to pass to
# `cancel_and_drain_or_report`"* -- and it was false in the way this repo keeps paying
# for: it was `classify-289.py`'s output, quoted as if it were a measurement.
# `test_live_outbound_serialized.cpp` builds real `system_clock_source`s and arms
# `quiesce_on_exit` guards with them, while the classifier's CLOCK pattern named only MOCK
# clocks and member-access spellings -- so it read that file as clock-free. The pattern is
# widened in this same change, with a control that goes `!!SILENT!!` when the widening is
# reverted.
# ⚠️ NO COUNT IS WRITTEN HERE, and that is the second lesson of this paragraph rather than
# a style choice: the draft that corrected the false claim put TWO COUNTS of its own in
# ("four ... and six"), and both were wrong -- inside the paragraph whose whole subject is
# a number quoted as if it had been measured. Derive them, do not read them:
#   grep -c 'make_shared<fixpp::core::system_clock_source>' tests/session/test_live_outbound_serialized.cpp
#   grep -c 'quiesce_on_exit ' tests/session/test_live_outbound_serialized.cpp
#
# ⚠️ TWO SITES HAVE A REAL CLOCK IN SCOPE AND THEY RESOLVE DIFFERENTLY, so the batch is
# one recipe shape and not one call. `cancel_sleeps()` has power only where a clock-parked
# frame can EXIST at the site, and at neither can one:
# `CloseCancelsBlockedPublicSend/close` runs under `make_acceptor_cfg`'s
# `heartbeat_interval = 0s`, so no liveness loop is ever spawned, and
# `StopDuringLivenessWriteNoCrash/open` is reached before the session is Active, so the
# loop does not exist yet. The second therefore takes the plain drain. The first does NOT,
# for an unrelated reason: a live `ControlledWriteTransport` is attached there with a
# blocked write armed, and the same scope already tears down with
# `cancel_and_drain_or_report(..., transport)` via `quiesce_on_exit`. A site drain
# strictly weaker than the one its own scope runs is the wrong way round, so that site
# passes the clock and the transport too. The reason is the TRANSPORT, not the clock.
#
# ⚠️ WHAT THE ARMS MEASURED, STATED AS WHAT THEY MEASURED. `ci/pump-seam-arm.sh` forces a
# miss AT WINDOW-OPEN, which PRESERVES the state at entry and cannot MANUFACTURE one: the
# forced state is a healthy exchange not yet dispatched, and the drain then completes work
# the window would have completed. A REAL miss is the opposite condition by definition --
# the exchange did NOT finish inside its window. So `RESIDUAL=0` across these labels is
# evidence that the drain reaches a fixed point when the exchange is HEALTHY; it is not
# evidence that it does when the exchange is WEDGED.
# [[feedback_a_forcing_mechanism_cannot_manufacture_the_state_it_preserves]]
#
# ⚠️ AND AT ONE SITE THE ARM IS WEAKER STILL. `CloseCancelsBlockedPublicSend/close`'s
# future is ALREADY READY when its window opens (the test bounded-waits it eight lines
# above), so forcing produces a miss branch whose drain resumes no frame suspended by THIS
# site. Batch 12 recorded the same shape at `LO_InboundLogout_Confirm/close`
# (`ci/red-arms/batch12-spotcheck.tsv`); it is noted here so this arm's green is not read
# as more than it is.
#
# ⚠️ ONE SITE REACHES DRAIN SURVIVOR CASE (ii) AND ITS REMEDY IS NOT A CLOCK ARGUMENT.
# `MakeAcceptedAdoptsRealAcceptedSocketAndHandshakes/accept` leaves a residual under a
# bare `drain_or_report`: the accept is still outstanding and the client coroutine is
# parked on a live TLS transport it moved in. It closes the acceptor first. That is
# per-site code and NOT a promotion to a primitive -- the graduation condition at
# `tests/support/pump_until_ready.hpp` asks for a SECOND FILE, and one file is one file.
#
# Textual arms -- the stronger witness -- are in `ci/red-arms/batch14-spotcheck.tsv`.
# Run both. What forcing does, and why a silent arm is NO-SUCH-SITE rather than a pass,
# is `ci/pump-seam-arm.sh`'s own contract; that script's header forbids restating it
# here, and an earlier draft of this file restated both anyway.
