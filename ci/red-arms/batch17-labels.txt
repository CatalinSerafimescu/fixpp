# ci/red-arms/batch17-labels.txt -- the seam-forceable sites of #289 batch 17.
#
# Feed to:  bash ci/pump-seam-arm.sh linux-clang-debug ci/red-arms/batch17-labels.txt
#
# One label per line. Every line here is a site that passes its label to
# `run_to_exhaustion_or_report`, which reaches the same `forced_miss_here` strcmp
# namespace as `run_window_then_ready` / `pump_until_ready` / `pump_until`.
#
# ⚠️ `ci/pump-red-arm.sh` CANNOT ARM THESE, and that is structural, not an omission.
# The textual driver rewrites a `run_window_then_ready` CALL into a forced miss; these
# sites do not spell that call. Batch 13 hit the same wall with `pump_until_ready` and
# recorded it there. So the seam driver is the ONLY driver for this batch, which raises
# what the seam driver's own header calls its blind spot: it accepts any of the three
# report tails, so a site that called this primitive and reported `kWindowMiss` by
# copy-paste would read RED here with nothing to contradict it. What closes that for
# this batch is that no site spells its own miss branch -- the branch is INSIDE
# `run_to_exhaustion_or_report` and there is exactly one of it. Re-derive:
#   git grep -c 'run_to_exhaustion_or_report' -- tests/ include/ src/
#
# ⚠️ EVERY LABEL IS `Suite::Case`, OPTIONALLY `/future`, AND THE SHAPE IS LOAD-BEARING
# TWICE. `ci/pump-seam-arm.sh` derives a gtest filter from the text before `::`, so
# `Suite::...` narrows the arm to that suite's cases rather than running the whole
# binary; and `Suite::Case` is unique by construction, which is what
# `ci/pump-label-uniqueness.sh` gates. A `/future` suffix appears only where one TEST
# holds more than one migrated site.
#
# ⚠️ `spawn_and_run` is the one label here that is NOT `Suite::Case`: it is a
# value-returning FILE-LOCAL helper (tests/tls/test_load_credentials_cancellation.cpp),
# so it has no enclosing test to name and its miss branch returns
# `kWindowMissSentinel`. The seam driver takes the unfiltered fallback for it, by
# design -- a label with no `::` cannot name a suite.
#
