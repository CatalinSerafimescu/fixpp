# fixpp

`fixpp` is a modern C++23 FIX protocol library targeting zero-copy parsing, lock-free hot paths, an ABI-agnostic C interface, Python bindings, and a gRPC + iceoryx2 service wrapper. It covers FIX 4.0 through 5.0SP2/FIXT.1.1. This site documents the feature roadmap and the design artifacts for each shipped or in-progress feature — it is generated automatically from the source repository and reflects the current state of `main`.
