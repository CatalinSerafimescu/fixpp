# tools/abi_history/error_codes_v1.txt
#
# C-ABI fixpp_error_t occupancy audit trail — append-only per [const §X.4].
# Rewritten by 049-c-abi-handles-errors (T013, FR-012/E-6) from the
# log/otel forward-reservation form to the published-code form.
#
# Format (one line per PUBLISHED code):
#   <numeric>\t<FIXPP_ERR_SYMBOL>\t<introducing_minor>
#
# introducing_minor is the uint16_t C-ABI MINOR ordinal at which the code was
# first published. Every code below was published in C-ABI 0.2.0 → minor 2.
# This is the column translate_for_consumer(code, consumer_minor) consumes for
# the forward-compat downgrade (data-model E-5): introducing_minor > consumer_minor
# → FIXPP_ERR_UNKNOWN. Stability binds only at MAJOR==1 ([const §X.4]).
#
# CI rule (tools/check_capi_occupancy.sh): every `#define FIXPP_ERR_*` in
# include/fix/c_api/error.h appears here with an unchanged numeric→symbol
# binding; a redefined slot fails CI.
