# Contract: Build Option & Verification Gates

## B-1 — `FIXPP_CODEGEN_FIX_LATEST` (CMake BOOL, CACHE, default ON)

| State | Guaranteed behavior |
|-------|---------------------|
| **ON** (default) | The codegen emits the `fixpp::vlatest` tier from `OrchestraLoader` over `OrchestraFIXLatest.xml`; the tier is compiled and available. |
| **OFF** | No `vlatest` generation or compilation. The build succeeds and produces output for the legacy tiers **byte-identical** to a `main` build without this feature. |

- **Invariant**: with the option ON *or* OFF, the v42/v44/v50sp2/vt11 generated bytes are unchanged (additive-only).
- **CI**: the ON path runs the **full sanitizer/preset matrix** (identical coverage to legacy tiers); a dedicated **OFF-path** job asserts the byte-identical legacy-only output.

## V-1 — Completeness census (FR-006) — MUST assert, not observe

- Ground truth = messages+fields enumerated **directly from raw `OrchestraFIXLatest.xml`** (components resolved, groups recursed to all depths), independent of `OrchestraLoader`.
- Assertion = **exact-set equality** (symmetric difference empty) vs the emitted `fixpp::vlatest` set, at message level (181==181) **and** per-message full field-set level.
- **Discrimination**: proven RED under a synthetic dropped-message mutation AND a synthetic dropped-field mutation (mutation-tested witness). A census that cannot go red is a false-green and fails this contract.

## V-2 — Typed round-trip (FR-007, SC-002)

- All **181** messages: construct via `build_<Msg>` → serialize → read back → assert field-for-field equality. **Zero skips.** A skipped message fails the gate.

## V-3 — Dispatch-exclusion witness, BOTH surfaces (FR-009, SC-005)

- Assert (a) `dispatch_application` for a FIX-Latest-only MsgType → existing fail-loud default (not a `vlatest` class); (b) `reify_dispatch_application` for a raw FIX-Latest-only wire message → does NOT silently yield a `vlatest`-typed owner (pin the actual deferred behavior — mis-resolve-to-v50sp2-default or fail-loud — as the ApplExtID feature's regression anchor); (c) each generated switch contains **exactly one** `application_version::v50sp2` case (injective map preserved).

## V-4 — Determinism golden (R8)

- The `vlatest` codegen output is byte-stable vs the checked-in golden; a non-deterministic or stale emit fails the determinism test under the **full** ctest (not a narrow target).

## V-5 — Fail-closed on unknown datatype (FR-010)

- Codegen over a synthetic Orchestra fragment carrying an unmapped datatype MUST fail closed (thrown, non-zero exit), never emit a mis-typed field.

## V-6 — Frozen-surface gates (FR-008, SC-004)

- The existing C-ABI symbol-golden / ABI-golden gate and the Python surface show **zero** diff.
