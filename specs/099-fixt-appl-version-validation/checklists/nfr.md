## NFR-003 and SC-007: the walk count and memory

- [ ] CHK020 Is "distinct" defined one way? NFR-003 says "each distinct dictionary", W-15 computes M "from the distinct `Dictionary*`". Two TOML sessions with one `dialect_overlay` text may each merge a separate `Dictionary`. Is the resulting M, and its cost, stated? [Clarity, Spec §NFR-003, contracts W-15, Spec §FR-018]
- [ ] CHK021 Do NFR-003, SC-007, research R-3 and W-15 give one formula for M: registry slots, transport dictionary, each S, plus `{d, S}` per pair source? "N sessions on M distinct route tables" is defined by that sum in one place only. [Consistency, Spec §NFR-003, Spec §SC-007, data-model E-1, contracts W-15]
- [ ] CHK022 SC-007's heap bound compares against "one copy of the smallest application dictionary it routes to". Is that comparand well-defined and large enough to mean something when a session routes to a minimal test dictionary, and when it routes only to FIX 5.0 SP2, where the bound is 13 MB? [Measurability, Spec §SC-007, research R-3, contracts W-15]
- [ ] CHK023 An added session with a new S that declares a header pair adds `{d, S}` tables, each a full copy. Does SC-007's "an added session adds … less heap" carve this out, or does its "M" absorb it? [Consistency, Spec §SC-007, Spec §NFR-003, research R-20]
- [ ] CHK024 Is a whole-engine memory cost stated? Research R-3 gives 13.35 MB and 14.69 MB per table, and the set holds one per route table, on any engine with a FIXT session, even a non-validating one. Two engines hold two sets. Is that disclosed as a cost a host should plan for? [Gap, research R-3, Spec §NFR-003]
- [ ] CHK025 Is `start()`'s duration a requirement at all? Research R-3 and plan give about 0.5 s and 3.3 s "on this machine". Is it stated that these are not budgets, and that no comment may carry them? [Clarity, plan owner's information list, research R-3, tasks T038]
- [ ] CHK026 NFR-003 carves out a directly constructed session and a C-ABI session's snapshot. Is each carve-out's walk count stated, so that a reader can derive W-15's "M plus one per C session" and research R-3's "walks twice where it walked once"? [Completeness, Spec §NFR-003, Spec §SC-007, research R-3, contracts W-15]
- [ ] CHK027 "Walks" means `as_table_view` calls, by W-15. Does a load through `dict::load_any` for an extra, or a `dict::header_length_pairs` call, which E-3 places "at configuration time only", count as one, and is that stated? [Clarity, Spec §NFR-003, data-model E-3, contracts W-15]
- [ ] CHK028 `reserve(256)` adds one block per FIXT session. Is its size inside SC-007's bound on every comparand, and is that bound's arithmetic stated as a condition rather than left to the test? [Assumption, data-model E-10, Spec §SC-007]
