# Contract: witnesses and mutants

An FR × shape × site × mutant matrix. W-4, W-5 and W-9 walk data-model E-7's cell ids, and each mutant names the code it changes and the cell that goes RED on that alone. **A witness with no way to report non-zero is a defect here.**

Unless a row says otherwise, a witness is a real `Session` driven with raw frames. **Shapes** are the spec's T, A, L. **RED-first**: W-1 to W-10 and W-19 run against `c0a828ef`'s behaviour before the code; a cell that is green on that tree says so in its row. The expected output for W-4, W-5 and W-9 on that run is the keyed logs of research R-18, read line by line, by shape, on or off, arm and input. **Mutants** run from a separate worktree, reused and batched by binary, whole binary, unfiltered, `strings`-checked fresh, and must turn the named cell RED.

Sites are research R-7's. Dispatch sites are D-1 to D-7. Fields: 3115 is FIX Latest only and float-typed, so a valid frame uses `3115=1.5` (measured: `3115=x` draws 373=5, not 373=2). Pick a FIX 4.4-only pair by a recomputed set difference over the vendored XML, in the test.
