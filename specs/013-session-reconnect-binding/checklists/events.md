- [x] CHK002 Is the ring-buffer capacity for `Session::recent_events()` specified — fixed N (and if so, what N)? Operator-tunable? Documented overflow / wraparound policy? [Coverage, Gap] — SPEC-FIXED: Added to spec.md §FR-035: "Multiple events during a single Logon attempt are emitted in strict emission order and stored in the ring buffer FIFO. - [x] CHK027 Are requirements for `credentials_rotated` on a no-op rotation (same cert_source / matching SHA-256 passed) specified — emit event, suppress event, or operator-tunable?
