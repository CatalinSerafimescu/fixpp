# Phase 1 Data Model: Test-Binary Grouping

No runtime data model (build-infra feature). The "entities" are the build/measurement artifacts and their relationships.

## Entities

### Test module
- **What**: a `tests/<module>/` directory with its own `CMakeLists.txt`. 23 total, out of 25 `tests/` subdirectories (`tests/abi/` and `tests/support/` are each fixtures-only, not modules). The unit of rollout.
- **Attributes**: `name`; `groupable_cpp[]`; `standalone_cpp[]`; `buckets[]`; per-preset baseline size (from CSV).
- **Lifecycle**: `baseline → grouped (buckets + carve-outs defined) → verified (8 presets green, delta recorded) → done`.

### Grouped bucket
- **What**: one `gtest_discover_tests` executable compiled from ≥1 isolation-safe, link-compatible, label-homogeneous `.cpp`.
- **Attributes**: `target_name`; `sources[]`; `link_libs` (union of members'); `labels` (shared set, re-applied via `PROPERTIES LABELS`); optional homogeneous `ENVIRONMENT`.
- **Invariants**: label-homogeneous (FR-003); every member isolation-safe (FR-002/D3); link_libs = union of member deps (FR-005); relinking touches only this bucket (FR-013).

### Standalone test
- **What**: a test kept as its own `add_executable` + `add_test(NAME <target>)`, per the FR-002/D3 taxonomy.
- **Attributes**: `target_name`; `ctest_name`; `labels`; per-target `ENVIRONMENT`/`TIMEOUT`/`compile_defs`/`link_libs`; `reason` (why standalone).
- **Invariants**: ctest name preserved (so `ctest -R <name>` still resolves); all per-target properties preserved verbatim.

### Disposition record
- **What**: the per-test decision proving FR-011 (100% accounted for).
- **Attributes**: `cpp`; `decision ∈ {grouped:<bucket> | standalone:<reason>}`; optional `odr_action` (in-test rename | carve-out).
- **Where**: per-module section in the feature's disposition ledger (tasks.md rows + the verify/close-out record).

### Baseline inventory
- **What**: the committed 2026-07-10 per-module/per-preset size table — comparison basis for all deltas.
- **Attributes**: rows `(preset, module, binaries, total_bytes)`; regenerated by `inventory.sh`.
- **Invariant**: the *before* side of every module delta references this snapshot, not a freshly re-measured pre-state (which would drift).

## Relationships

```
Test module 1───* Grouped bucket
Test module 1───* Standalone test
Test module 1───* Disposition record   (one per .cpp; sums to every .cpp in the module)
Grouped bucket *───* .cpp source        (a .cpp belongs to exactly one bucket OR is standalone)
Baseline inventory 1───* module rows    (the before-delta reference)
```

## Preserved external contract (not owned, but constrained)

- **CTest test identity**: gtest `Suite.Name` per case — UNCHANGED by grouping (audits key on it).
- **CTest labels**: re-applied at case granularity on grouped binaries; unchanged on standalone.
- **Coverage-index / completeness audit keys**: `.cpp` stem + `Suite.Name` — UNCHANGED.
- **Per-preset built/run test set**: identical before/after (FR-007).
