## Summary

Ship the **wire-layer core** for fixpp v1.0 — the public C++ surface that the session-FSM Phase-4 module will consume to drive bytes onto the network, and that `011-tls-policy`'s `SslCtxConfig` + `verify_peer` plug into to perform TLS handshakes. This slice locks the **byte-stream interface contract + the OpenSSL-driven default impl + the multi-session acceptor + the deterministic mock test seam**; the session FSM (Logon / Heartbeat / Resend / Reset / Logout transitions, reconnect loop, CompID-to-TLS-identity binding) is owned by the post-this-feature session-module Phase-4 spec.

Nine public types land under `include/fixpp/transport/`:

1. **`fixpp::transport::Transport`** (abstract, **5 pure-virtuals** AT the `[const §XIV.2]` cap: `async_connect`, `async_read_some`, `async_write`, `cancel`, `close`) — the encryption-agnostic byte-stream contract. No defaulted-virtual headroom (deliberately AT-cap so the surface is impossible to extend without a major-version bump).
2. **`fixpp::transport::TlsTransport`** — sub-interface extending `Transport` with **1 additional pure-virtual** (`async_handshake`) using 1 of the sub-interface's 5-slot budget. The remaining 4 slots are reserved empty headroom for post-v1 PSK (T-012), explicit renegotiation control, or an early-data hook. Inherits virtually from `Transport`.
3. **`fixpp::transport::ConnectInfo`** + **`fixpp::transport::handshake_result`** — owning-by-value PoDs returned from `async_connect` and `async_handshake` respectively. `handshake_result` carries `peer_identity` (consumed by the session-module Phase-4 spec for T-041 CompID-to-TLS-identity binding), the captured `Pinset::snapshot()` per `[2g §6.5.1]` BINDING CONTRACT, and the negotiated cipher-suite name. No accessor pure-virtuals are published; the FSM holds `handshake_result` by value for the session lifetime per the `[2c §4.8]` `owning_message_t<>` precedent.
4. **`fixpp::transport::Endpoint`** — value type for `(host, port)` initiator endpoints and `(bind_addr, bind_port, backlog)` acceptor endpoints; auto-detects address family from the host string; admits IPv6 zone-ids (`fe80::1%eth0`).
5. **`fixpp::transport::ReconnectPolicy`** — value type carrying a **user-supplied schedule array** (QuickFIX/J-aligned per Clarifications 2026-05-27 Q2=C): `std::pmr::vector<std::chrono::milliseconds> schedule` + `double jitter` + `std::uint32_t max_attempts`; `defaults()` materialises `[100ms, 200ms, 400ms, 800ms, 1.6s, 3.2s, 6.4s, 12.8s, 25.6s, 30s]` × jitter=0.10 × max_attempts=10 (cumulative 73–89 s envelope per design-doc §1.1); `defaults_quickfix_compat()` returns `{[30s], 0.0, 0}` for industry-canonical operators. `delay_for_attempt(n)` returns `schedule[min(n, schedule.size()-1)] × (1 + uniform(-jitter, +jitter))` matching QuickFIX/J `IoSessionInitiator::computeNextRetryConnectDelay():318-319` plateau-at-last semantics.
6. **`fixpp::transport::Transport::Config`** — per-session knobs: `max_read_window_bytes` (256 KiB, matches `[2b §1.2]` `default_max_frame_bytes`), `max_write_size_bytes` (1 MiB, one v1.0-max frame + 4× headroom for derivatives), `tcp_recv_buf_bytes`/`tcp_send_buf_bytes` (0 = OS auto-tune), `tcp_nodelay` (`true` — Nagle OFF per Clarifications Q5=A, aligning with QFJ + Fix8; deliberately diverges from QFC's Nagle-ON anomaly), `so_linger_enabled` (`false` — matches Fix8 explicit setLinger + QFJ/QFC OS-default), `tls_handshake_timeout` (30 s), `tls_close_timeout` (1 s), TCP keepalive group (off by default).
7. **`fixpp::transport::Listener`** + **`fixpp::transport::asio_listener`** — multi-session acceptor (T-005); `Listener` ships **1 pure-virtual** (`async_accept`) returning `asio::awaitable<expected_t<std::unique_ptr<Transport>>>` per `[2h §4.6]:810`. The `cancel()` API is a CONCRETE-IMPL contract on `asio_listener` (not a pure-virtual on the abstract `Listener` base; the design doc surfaces engine-scoped Listener cancellation through `[2h §6.4.1]:1124`, NOT through a pluggable `Listener::cancel` method). `asio_listener::cancel()` does exactly three things (Clarifications 2026-05-27 Q4=A): (1) close the listening socket; (2) complete in-flight-but-unresumed `async_accept` with `transport_accept_cancelled` per `[2h §6.6]:1191`; (3) leave already-resumed-but-not-yet-consumed `unique_ptr<Transport>` results UNAFFECTED.
8. **`fixpp::transport::asio_tls_transport`** — the v1.0 reference `TlsTransport` impl over ASIO `tcp::socket` + `asio::ssl::stream<tcp::socket>` over OpenSSL on Linux + Windows per `[const §XII.1]`. Configures `SSL_CTX` per `[2g §4.5.1]`'s normative `SecurityProfile`-to-OpenSSL-mode mapping table EXACTLY; pins `SSL_OP_NO_RENEGOTIATION | SSL_OP_NO_COMPRESSION | SSL_OP_NO_TICKET | SSL_OP_NO_EARLY_DATA` per `[FIXS §3.2]` + `[const §XII.3]`; rejects PSK with `transport_psk_unsupported` (T-012 P2 deferred).
9. **`fixpp::transport::TransportFactory`** + **`fixpp::transport::test::mock_transport`** — the `[arch §6]` rule-4 factory producing `Transport` instances with the canonical surface re-emitted verbatim from `[2h §4.7]:907-910` (`make(asio::any_io_executor exec, fixpp::tls::SslCtxConfig ssl_cfg, std::pmr::memory_resource* mr) noexcept -> expected_t<std::unique_ptr<Transport>>`), plus the public-test-header deterministic in-memory `Transport` impl per `[2h §4.8]:960` (`fixpp::transport::test::` namespace, honouring every cancellation contract `asio_tls_transport` honours). Factory ownership is `std::unique_ptr<TransportFactory>` matching the `[2e §4.4]` `MessageStoreFactory` precedent; engine anchor is `EngineConfig::default_transport_factory` (Appendix D §D.1 flips it from `shared_ptr` → `unique_ptr` per `[arch §5.6]`); per-session override is `SessionConfig::transport_factory_override` (Appendix D §D.2). The session-open sequencer builds the `SslCtxConfig` ONCE and reuses it across reconnect attempts; the FSM passes `(exec, ssl_cfg, mr)` into `make(...)` on each attempt. **Reconnect mints a FRESH `Transport` via the same `TransportFactory`** per Clarifications 2026-05-27 Q1=B — matching QuickFIX-cpp / QuickFIX/J / Fix8 industry pattern.

Plus the error envelope:

10. **`error::transport_*` variants** — the **22-variant set** re-emitted from `[2h §6.6]:1167-1204` verbatim. C-ABI coalescing groups owned by 2i: `FIXPP_ERR_TRANSPORT_LIFECYCLE` (resolve/refused/timeout/already-connected/already-closed/in-progress/reconnect-limit), `FIXPP_ERR_TRANSPORT_IO` (eof/truncated/error/short/write-error), `FIXPP_ERR_TRANSPORT_HANDSHAKE` (handshake-failed/timeout — joins `[2g §6.6]` `FIXPP_ERR_TLS_HANDSHAKE` at C ABI), `FIXPP_ERR_TRANSPORT_CONFIG` (factory-failed/psk-unsupported), and `FIXPP_ERR_CANCELLED` (re-uses `[const §XI.2]` for the 5 `*_cancelled` rows). The 15 `tls_*` variants from `[2g §6.6]:986-1004` (per the explicit "(15 variants.)" count at `[2g §6.6]:1004`) surface UNCHANGED — 2h MUST NOT re-translate or coalesce them.

**Catalogue rows owned**: T-001 (Transport interface), T-002 (TlsTransport sub-interface), T-003 (asio_tls_transport default impl), T-004 (Endpoint + ReconnectPolicy), T-005 (Listener + asio_listener acceptor). **Cross-cuts owned with 011-tls-policy**: T-039 (`verify_peer` predicate is owned by 011; OpenSSL `SSL_VERIFY_PEER` callback wiring lives here), T-040 (`cert_source` consumes operator-distributed secrets — wiring of `SslCtxConfig` into OpenSSL lives here). **Cross-cut into session/ Phase-4**: T-041 (`handshake_result.peer_id` value supplied here; CompID-to-TLS-identity binding logic in the session-module spec). **Performance Goals** (per `[2h §6.3]` Tier 1 ceilings, applied to 5 % regression gate per `[const §VIII.2]`):

- **`Transport::async_read_some` completion-handler dispatch on strand (warm cache, HALO-fired):** ≤ 200 ns p99 — strand `dispatch` (≈ 50–100 ns matching `[2d §6.3]`) + ASIO completion-token plumbing (≈ 50–100 ns) + awaitable resume (≈ 5–20 ns under HALO).
- **`Transport::async_write` call-site issue on strand:** ≤ 200 ns p99 — same arithmetic as `async_read_some`. (Wire transmit time is OS+network-bound, NOT budgeted.)
- **`Transport::async_connect` TCP-only loopback (warm DNS cache):** ≤ 5 µs p99 (I/O-bound soft ceiling; CI flags > 2× regression).
- **`TlsTransport::async_handshake` TLS 1.3 1-RTT against loopback peer (self-signed, no `verify_peer` cost):** ≤ 10 ms p99 (soft) — dominated by OpenSSL handshake (1.5 RTT + ECDH + RSA-PSS sign). CI flags > 2× regression.
- **`verify_peer` policy core** (consumed from 011): ≤ 50 µs p99 — cited from `[2g §6.3]` row 4 directly; 2h does NOT re-budget.
- **`cancel()` synchronous on strand:** ≤ 1 µs p99 — one ASIO cancellation_signal emit; bounded.
- **`close()` TLS bidi shutdown to loopback peer (warm):** ≤ 100 ms p99 (soft) — bounded by `Transport::Config::tls_close_timeout` (1 s default). CI flags any case exceeding the configured timeout.

CI fails on > 5 % regression on the hot-path rows (`async_read_some` / `async_write`); > 2× on the I/O-bound rows (`async_connect`, `async_handshake`, `close`). Per `[const §VIII.1]` / `[const §VIII.2]` / `[const §VIII.3]`, these are perf-sensitive and benched in `bench/transport/`.

**Constraints**:

- **Zero global `new`/`delete` on the read-path completion-handler dispatch** per `[const §VIII.5]` / `[const §XV.1]` (extended here per `[2h §8]` recap — the bytes pass through 2h's completion handler before `Framer::feed` sees them). Verified via `tests/perf/test_transport_read_alloc_guard.cpp` (`[2h §9 seam #4]:1345`) + the **dual allocation guard** (`counting_resource` PMR-routed accounting AND mallocnesia LD_PRELOAD interception of global `operator new` / `malloc`) per `[[feedback_tracking_pmr_resource_false_pass]]`. **The bytes-from-kernel cost is OS-side and not counted; this constraint covers the ASIO-and-engine plumbing only.**
- **PMR allocation permitted** on cold paths only: `asio_tls_transport::cfg_.mr` for the `SslCtxConfig`'s `peer_identity` SAN-string copies (per `[2g §4.5]`), the OpenSSL `SSL_CTX*` configuration arena, and any `peer_identity` material `verify_peer` allocates at handshake time. PMR throws routed through `[2a §4.2]` `trap_throw` and surface as `transport_*` variants — NO PMR throw escapes as a C++ exception across the public surface.
- **Construction-time throws** permitted per `[arch §5.3]` carve-out (engine bootstrap before any session is open); the `TransportFactory::make(...)` wraps the boundary in `expected_t<...>` so non-construction-time callers (2i C ABI, runtime reconnect mint) never see a thrown exception.
- **ASIO native cancellation slots end-to-end** on every async method per `[const §XI.2]`; the slot is read with `co_await asio::this_coro::cancellation_state`; `cancellation_type::total` MUST surface as the matching `transport_*_cancelled` variant per `[2h §6.6]` — NO thrown exception across the public surface. Two-phase close per `[2d §4.7]` per-mode effect table extended in `[2h §6.4.1]` MUST be honoured.
- **In-flight exclusivity API-level contract**: at most one in-flight `async_read_some` + one in-flight `async_write` per `Transport` instance; concurrent second call MUST complete IMMEDIATELY with `transport_read_in_progress` / `transport_write_in_progress` per `[2h §6.6]`. Strand serialisation is defence-in-depth, NOT the binding contract.
- **Per-session strand serialisation** (`[const §XI.4]`) for the coroutine that calls into `Transport`; transport callbacks rebind to the session executor on the read-path completion (the FSM owns the strand; 2h hops onto it).
- **No C-ABI surface emitted** by 012 (`[const §X.2]` nm check inherited). 2i bridges; 012 publishes the C++ source-of-truth + per-doc-prefix `FIXPP_ERR_TRANSPORT_*` coalescing-group naming rule.
- **Pluggable interface caps**: `Transport` ships **5 pure-virtuals AT** `[const §XIV.2]`'s ≤ 5 cap (deliberate — see Summary). `TlsTransport` ships **1 ADDITIONAL** (= 1 of the sub-interface's 5-slot budget). `Listener` ships **1**. No `dlopen` plugin loading per `[const §XIV.4]`; user-side `Transport` impls (SHM/DPDK post-v1) compiled into the user binary against fixpp.
- **No transport-internal write queue** per `[arch §5.8]` + `[const §XV.15]` — the strand IS the depth-1 queue; `block` mode is the only v1.0 mode on app/session message paths; `drop-oldest` is banned.
- **Durable-before-transmit binding** per `[2e §6.1.4]`: `async_write` MUST NOT be called until the corresponding `store(committed_span)` has linearised; a cancelled `async_write` MUST NOT trigger any rollback of the persisted frame. 2h's API construction guarantees the surface; the FSM (post-this-feature) owns the sequencing.
