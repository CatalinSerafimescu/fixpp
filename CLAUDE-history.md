- **`066-dict-backed-inbound-parse`** — PR #181 (squash `4e3be8e5`), 2026-07-09, gate-a-done + gate-b-done. The **shipped** inbound receive parse (`Session::parse_and_dispatch_`) built its `wire::Parser` **dict-free**, so no inbound-dispatched `MessageView` (C-ABI or C++ typed) carried group membership — the context-scoped membership 062/063 delivered was never consulted on a real dispatched message (only on the unit-tier `Parser<Index>{dict}` those features' tests used). Strict in-group membership (QuickFIX/J-aligned, permissive→strict, B-066-1); scoped to the 6 group-registering dicts (FIX40/41/42 group-blind, L-066-1). Does NOT fix the C-ABI **nested** positional last-instance defect (L-063-2 / #179 / feature 065). Gate B converged (0 waivers). Post-Gate-B CI fixes in the squash (native-MSVC + local-libc++): OOM-witness libstdc++ gate (`2a78f31e`), MSVC-debug `_Container_proxy` grouped-read skip (`9d67b028`), and a **real production fix** — `OffsetTable::group_slices()` reserve tightened to the group-instance bound so a large inbound group can't silently read empty when MSVC's STL metadata exhausts the fixed 16 KiB null-upstream parse arena (`cc169700`). Amends W-006/W-007/CA-010 + coverage-index §3.2.
